## 八、技术决策记录

1. **VO 转换策略**：手动 `from()` 工厂方法，不引入 MapStruct，金额转 Long（分）
2. **登录锁定**：数据库原子更新 `fail_count = fail_count + 1`，5次/30分钟
3. **退款架构**：`RefundApplication`（用户申请层）与已有 `RefundOrder`（支付渠道层）分离
4. **会员自动升级**：在 `PaymentV1Consumer` 中异步触发，try-catch 隔离不影响主流程
5. **前端守卫**：三层守卫（AuthGuard → RoleGuard → GuestGuard），事件机制解耦 401 处理
6. **测试策略**：纯 Mockito 单元测试，不依赖 Spring 上下文，TableInfoHelper 初始化 MyBatis-Plus 缓存
