## 逐项详情

### ✅ #17 商户趋势查询逐月循环 → GROUP BY

`MerchantServiceImpl.getMerchantTrend()` 和 `getSalesTrend()`：

- 原先：逐月 6 次 `selectList` 循环 → N 次 SQL
- 现在：单条 `selectMaps` + `DATE_FORMAT GROUP BY` → 1 次 SQL

```java
.select("DATE_FORMAT(create_time, '%Y-%m') AS month", "COUNT(*) AS cnt")
.groupBy("DATE_FORMAT(create_time, '%Y-%m')")
```

末段循环仅补齐缺失月份，不访问数据库。实现干净。

### ✅ #18 订单项逐条 insert → saveBatch

`AppOrderServiceImpl.insertOrderItems`：

- 原先：`for` 逐条 `insert`
- 现在：`collect(toList()) → salesOrderItemMapper.insertBatch(items)`

一次批量写入，解决 N 次网络往返。

### ✅ #20 请求链路追踪 MDC + Correlation ID

新增 `filter/TraceFilter.java`：

- 读取或生成 `X-Request-Id`
- 放入 `MDC.put("requestId", ...)`
- `finally` 块 `MDC.remove`
- 响应头回传

logback 若在 pattern 中加入 `%X{requestId}` 即可串联全链路日志。
