## 🔴 阶段一：生产阻断（P0 · 4 项 · 预计 2 天）
### 1.1 Dashboard 全表加载 OOM ⭐
**位置**：`payment-system/src/main/java/com/payment/service/impl/V1AdminServiceImpl.java`  
**影响方法**：`getDashboardOverview()` (行136-169)、`getTradeOverview()` (行286-327)
**现状**：
```java
// 三张主表直接 selectList，无任何过滤，全量加载到内存
List<SalesOrder> allOrders = salesOrderMapper.selectList(
    new LambdaQueryWrapper<SalesOrder>().eq(SalesOrder::getDeleted, 0));
// 几十万行 → OOM
```
**修复**：全部改为 SQL 端聚合（SUM/COUNT），不在应用内存中做统计。
```java
Map<String, Object> stats = salesOrderMapper.selectMaps(
    new QueryWrapper<SalesOrder>()
        .select("COUNT(*) AS total", "SUM(total_amount) AS totalAmount",
                "SUM(CASE WHEN pay_status='SUCCESS' THEN 1 ELSE 0 END) AS paidCount")
        .eq("deleted", 0)).get(0);
```
**风险**：低 — 需单元测试验证聚合结果与旧实现一致。  
**难度**：★★☆☆☆
---
### 1.2 merchant_balance 缺 version 列 ⭐
**位置**：`payment-system/sql/08_merchant_finance.sql` (行8-20)  
**影响表**：`merchant_balance`
**现状**：表无 `version` 列，乐观锁重试形同虚设，并发余额更新会丢失。
**修复**：
```sql
ALTER TABLE `merchant_balance` ADD COLUMN `version` INT NOT NULL DEFAULT 0
    COMMENT '乐观锁版本号' AFTER `total_withdrawal`;
```
Entity 加 `@Version private Integer version;`，所有余额变更处改为最多 3 次重试循环。
**风险**：中 — DDL 可能需停机，余额变更逻辑改动点较多。  
**难度**：★★★☆☆
---
### 1.3 积分账户无乐观锁重试
**位置**：`payment-system/src/main/java/com/payment/service/impl/MemberPointsAccountServiceImpl.java`  
**影响方法**：`grantPoints()` (行79-82)、`holdPoints()` (行117-120)、`releasePointsHold()` (行166-169)
**现状**：version 列已有（行46 `setVersion(0)`），但 updateById 返回 0 时直接抛异常，没有重试。
**修复**：三处改为最多 3 次重试循环：
```java
for (int retry = 0; retry < 3; retry++) {
    int affected = accountMapper.updateById(account);
    if (affected > 0) break;
    account = accountMapper.selectById(account.getId());  // 重读
    account.setPoints(Math.addExact(account.getPoints(), points));
}
```
**风险**：低 — 改动范围小，仅三处替换。  
**难度**：★★☆☆☆
---
### 1.4 前端无代码分割
**位置**：`salessystem/src/App.tsx` (行37-94)
**现状**：40+ 页面全部 `import X from './pages/X'` 静态引入，打包为单个巨型 chunk。
**修复**：全部改用 `React.lazy()` + `<Suspense>`，按路由分组：
- `chunk-user`：Home, Discovery, Cart, Wallet, Profile, Orders
- `chunk-admin`：AdminDashboard, AdminMerchants, AdminAnalytics...
- `chunk-merchant`：MerchantDashboard, MerchantOrders, MerchantProducts...
- `chunk-auth`：Login, Register
```tsx
const Home = React.lazy(() => import('./pages/Home'));
<Suspense fallback={<PageLoader />}>
  <Routes>...</Routes>
</Suspense>
```
**风险**：中 — 需验证 AuthContext/ToastContext 在 Suspense 下的行为。  
**难度**：★★★☆☆
