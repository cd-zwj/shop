## 3. 第三方 OAuth 登录

**现状**: `PlatformAuthProvider` 实体定义了 provider_code、client_id、client_secret 等字段。`V1AdminAuthProviderController` 提供 Admin 端 CRUD（list/get/create/update/enable/disable）。`ThirdPartyPlatformLoginHandler` 只做数据库查找已绑定用户，**没有真正的 OAuth 授权码流程**。前端 Login.tsx / Register.tsx 的 Github/WeChat 按钮只弹 toast。

**需要做的事**:
- [ ] 实现通用 OAuth2 授权码流程（code → token → userInfo）
- [ ] 微信 OAuth：code2session 接口、获取 openid/unionid
- [ ] 支付宝 OAuth：获取 auth_token 和用户信息
- [ ] GitHub/Google OAuth：标准 OAuth2 + OIDC
- [ ] 用户绑定/解绑第三方账号
- [ ] 新用户通过第三方登录自动注册
- [ ] 前端：第三方按钮跳转授权页 → 回调 → 绑定/登录

**涉及模块**: 后端 ThirdPartyPlatformLoginHandler、新增 OAuth2Service；前端 Login.tsx、Register.tsx、新增 OAuthCallback.tsx
