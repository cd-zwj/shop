### 3. 商户财务总览页改造

更新文件：

- `src/pages/merchant/MerchantFinance.tsx`

改动内容：

- 不再使用前端 mock 财务数据
- 真实展示：
  - 可提现余额
  - 冻结余额
  - 累计收入
  - 累计提现
- 真实展示积分规则快照
- 真实展示充值规则快照
- 真实展示最近提现记录

说明：

- 当前后端未提供独立“收支流水列表”接口，因此页面改为展示“余额汇总 + 规则快照 + 最近提现动态”，避免继续保留伪造流水数据

### 4. 商户规则页改造

更新文件：

- `src/pages/merchant/MerchantRules.tsx`

改动内容：

- 页面初始化时真实拉取：
  - 积分规则
  - 充值规则
- 支持编辑并保存积分比例与启用状态
- 支持新增、删除、启停充值梯度
- 保存时按后端接口要求整体替换充值规则列表

实现细节：

- 积分规则直接调用 `PUT /points-rule`
- 充值规则调用 `PUT /recharge-rules`
- 保存前做了前端基础校验：
  - 积分比例不能小于 0
  - 充值金额必须大于 0
  - 赠送余额不能小于 0
  - 赠送积分必须为整数且不能小于 0

### 5. 商户提现页改造

更新文件：

- `src/pages/merchant/MerchantWithdraw.tsx`

改动内容：

- 真实展示提现余额信息
- 真实展示提现记录列表
- 支持按状态筛选：
  - 全部
  - 待审核
  - 已打款
  - 已驳回
- 支持提交真实提现申请
- 支持展示驳回原因

提现申请字段按后端 `WithdrawalApplyDTO` 对接：

- `amount`
- `bankName`
- `bankAccount`
- `accountName`
