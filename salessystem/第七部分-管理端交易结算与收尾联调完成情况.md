# 第七部分 - 管理端交易结算与收尾联调完成情况

## 本阶段目标

完成管理端交易、订单、支付账单、充值订单、提现审核的真实接口接入，并补齐商户端商品图片上传能力，形成第 7 部分的联调闭环。

## 已完成内容

### 1. 新增管理端交易与提现服务

- `src/services/modules/adminTrade.ts`
  - 接入 `/v1/admin/trades/overview`
  - 接入 `/v1/admin/orders`
  - 接入 `/v1/admin/orders/{orderNo}`
  - 接入 `/v1/admin/payment-bills`
  - 接入 `/v1/admin/recharge-orders`
- `src/services/modules/adminWithdrawal.ts`
  - 接入 `/v1/admin/withdrawals`
  - 接入 `/v1/admin/withdrawals/{withdrawalId}/approve`
  - 接入 `/v1/admin/withdrawals/{withdrawalId}/reject`
- `src/services/modules/fileUpload.ts`
  - 接入 `/api/file/check-exists`
  - 接入 `/api/file/upload`

### 2. 扩展管理端类型定义

- `src/types/admin.ts`
  - 新增 `AdminTradeOverview`
  - 新增 `AdminOrderListItem`
  - 新增 `AdminPaymentBill`
  - 新增 `AdminRechargeOrder`
  - 新增 `AdminWithdrawal`
  - 新增 `FileExistsResult`
  - `AdminOrderDetail` 复用 `SalesOrderDetail`

### 3. 管理端页面完成真实接口改造

- `src/pages/AdminTransactions.tsx`
  - 接入交易总览统计
  - 接入订单列表
  - 支持关键词、订单状态、支付状态筛选
  - 支持跳转订单详情
- `src/pages/AdminOrderDetail.tsx`
  - 接入订单详情接口
  - 展示订单基础信息、金额信息、商品明细
- `src/pages/AdminPayments.tsx`
  - 接入支付账单列表
  - 支持业务类型、支付状态、支付渠道筛选
  - 订单类账单支持跳转订单详情
- `src/pages/AdminRecharges.tsx`
  - 接入充值订单列表
  - 支持钱包类型、业务状态、商户 ID 筛选
- `src/pages/AdminWithdrawals.tsx`
  - 接入提现审核列表
  - 支持商户名称、审核状态筛选
  - 支持审核通过
  - 支持驳回并填写原因

### 4. 商户端补齐文件上传能力

- `src/pages/merchant/MerchantProductEdit.tsx`
  - 接入商品图片上传
  - 上传成功后自动回填图片地址
  - 与商品编辑表单形成闭环
